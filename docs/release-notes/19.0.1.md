# Motrix 19.0.1 (fork build)

English | [简体中文](19.0.1.zh-CN.md)

This fork build uses upstream Motrix 2.3.0 plus changes through commit
`a45a729e985446a936167106af6b4173f06116aa`.

- Refresh waiting tasks beyond the first 1,000 using bounded, sequential pages.
- Deduplicate tasks that move between the active response and waiting pages.
- Preserve upstream request serialization, compact RPC fields, cached file
  metadata, virtualized lists, and pre-download torrent file selection.

Windows build artifacts are unsigned. This is a custom fork version; the
19.x version number does not identify an official upstream release.

When upgrading from the legacy 19.0.0 fork, follow the
[upstream migration guide](https://github.com/agalwood/Motrix/blob/v2.3.0/docs/legacy-migration.md)
and retain the original profile and engine database backups.
