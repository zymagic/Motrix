# Motrix 19.0.1（分支构建）

[English](19.0.1.md) | 简体中文

本分支构建基于上游 Motrix 2.3.0，并包含截至提交
`a45a729e985446a936167106af6b4173f06116aa` 的更新。

- 使用有界、顺序分页刷新超过 1,000 个的等待任务。
- 对在活动任务响应与等待任务分页之间发生移动的任务进行去重。
- 保留上游的请求串行化、精简 RPC 字段、文件元数据缓存、列表虚拟化，
  以及下载前的种子文件选择功能。

Windows 构建产物未签名。这是自定义分支版本；19.x 版本号不代表上游官方版本。

从旧版 19.0.0 分支升级时，请遵循
[上游迁移指南](https://github.com/agalwood/Motrix/blob/v2.3.0/docs/legacy-migration.md)，
并保留原始配置及引擎数据库备份。
